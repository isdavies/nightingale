# Nightingale

This repository contains code for an R package to visualise data from Florence Nightingale's mortality analysis. It is an exemplary R package for learning and trying out practices of research software engineering.

The code for the package is available in a [public GitHub repository](https://github.com/jansim/nightingale). You can install the development version of the package from GitHub:

```{r}
pak::pak("jansim/nightingale")
```

The authors of the package are Jan Simson and Fritjof Lammers.

## Data

Raw data used in this package is saved in data-raw/ in a .csv file. It is a dataset containing mortality data from the Crimean War, famously visualised by Florence Nightingale to argue for hygiene improvements in the military.

The dataset was extracted by Livnah from Datawrapper: <https://www.datawrapper.de/blog/recreating-nightingale-rose-chart>.

## Code

Scripts for processing the raw data can be found in data-raw/ and R/, and processed data is saved in data/. Functions for visualising the data and displaying it on a Shiny dashboard can be found in R/.

Function documentation is generated by the roxygen2 package and saved in man/. Unit testing can be found in tests/.

The repository uses Docker for environment management.
